# 🖋️ Inkpath v1.0 – Εγχειρίδιο Χρήστη

## Εισαγωγή

Το **Inkpath** δεν είναι απλώς ένα πρόγραμμα – είναι το εργαλείο των ονείρων σου για να δημιουργήσεις interactive ιστορίες, παιχνίδια επιλογών και ακόμα και εκπαιδευτικά σενάρια.  
Φαντάσου να έχεις τη δύναμη να γράφεις ιστορίες που ζουν, αναπνέουν και αλλάζουν ανάλογα με τις επιλογές του αναγνώστη.  
Με το Inkpath, αυτό γίνεται πραγματικότητα. Και όχι, δεν χρειάζεσαι πτυχίο σε αστροφυσική για να το χρησιμοποιήσεις. 😉

---

## 🛠️ Εγκατάσταση

### 💻 Προϋποθέσεις Συστήματος

- **Λειτουργικό**: Windows 10 ή νεότερο  
- **Αποθήκευση**: Τουλάχιστον 100 MB ελεύθερος χώρος  
- **Δικαιώματα**: Προτείνεται εκτέλεση ως **Administrator** (για να μην "τσακωθείς" με τα δικαιώματα αρχείων)

### 📦 Οδηγίες Εγκατάστασης

1. **Κατέβασε το Inkpath_Setup.exe**  
   - Από το GitHub releases ή την επίσημη ιστοσελίδα.

2. **Εκτέλεσε το installer**  
   - Κάνε διπλό κλικ και απλά πάτα "Next" μέχρι να τελειώσει ο οδηγός.

3. **Επιλογή Φακέλου**  
   - Προτείνεται ο προεπιλεγμένος φάκελος:  
     `C:\Inkpath\`  
     (Ναι, ξέρουμε, ο C: είναι ο αφεντικός του Windows.)

4. **Συντόμευση στην Επιφάνεια Εργασίας**  
   - Συνήθως είναι already checked. Άφησε το όπως είναι – δεν πιάνει πολύ χώρο.

5. **Finish & Enjoy**  
   - Πάτα "Finish" και έλα, πήγαινε να δημιουργήσεις την πρώτη σου ιστορία! 🎉

### ⚙️ Πρώτη Εκκίνηση

- Άνοιξε το Inkpath από το Start Menu ή την επιφάνεια εργασίας.
- Αν σου βγάλει μήνυμα από το UAC, πάτα "Ναι". Δεν θέλει να κλέψει τα bitcoin σου.
- Στην πρώτη εκκίνηση θα δημιουργηθούν τα αρχεία ρυθμίσεων αυτόματα. Everything’s magic.

## 🎮 Ξεκινώντας

### Η Κύρια Οθόνη (GUI)

Η διεπαφή χωρίζεται σε τρία βασικά πάνελ:

- **Αριστερά**: Διαχείριση nodes, κατηγοριών, αναζήτηση.
- **Κέντρο**: Επεξεργασία κειμένου, προσθήκη εικόνων, ήχων, επιλογών.
- **Δεξιά**: Preview, στατιστικά, play mode, ρυθμίσεις.

### Πρώτα Βήματα

1. **Πρόσθεσε το πρώτο σου node** → Κλικ στο "➕ Add".
2. **Γράψε την πρώτη σκηνή** → Περιέγραψε το σκηνικό, πρόσθεσε εικόνα ή ήχο.
3. **Δημιούργη επιλογές** → Σύνδεσε αυτό το node με άλλα.
4. **Παίξε την ιστορία σου** → Κλικ στο "▶️ Play Story" και δες πώς πάει!

## 🧩 Χρήση του Προγράμματος

### Βασικές Λειτουργίες

- **➕ Add Node**: Δημιουργεί νέα σκηνή.
- **📋 Copy/Paste**: Αντιγράφει nodes (γιατί να ξαναγράφεις τα ίδια;).
- **🗑️ Delete**: Διαγράφει nodes (με προειδοποίηση – μην πας να τα σβήσεις όλα τώρα).
- **📝 Templates**: Έτοιμες δομές για opening, combat, dialogue scenes.

### Προχωρημένες Λειτουργίες

- **🗺️ Graph View**: Βλέπεις οπτικά όλη την ιστορία σου.
- **✓ Validate**: Σου λέει αν έχεις broken links, dead ends ή loops.
- **💾 Auto-Save**: Αποθηκεύει κάθε 2 λεπτά, γιατί ξέρουμε ότι ξεχνάς.

## ❓ Συχνές Ερωτήσεις (FAQ)

**Ε: Γιατί μου λέει "Access Denied" κατά την αποθήκευση;**  
Α: Εκτέλεσέ το ως Administrator. Το Windows αγαπάει τα δικαιώματα περισσότερο από ό,τι εμείς τον καφέ μας.

**Ε: Μπορώ να το βάλω σε άλλο drive, π.χ. D:\;**  
Α: Μπορείς, αλλά το C:\ είναι πιο "φιλικό" με τα δικαιώματα. Αν επιμένεις, πρόσεχε τα permissions.

**Ε: Υποστηρίζει βίντεο ή variables;**  
Α: Όχι ακόμα. Μόνο εικόνες, ήχοι και πολύ φαντασία.

**Ε: Πώς κάνω backup της ιστορίας μου;**  
Α: Αποθήκευέ την συχνά (Ctrl+S) και αντιγράφου τον φάκελο της ιστορίας σε cloud ή εξωτερικό δίσκο.

## 🛠️ Αντιμετώπιση Προβλημάτων

### Το πρόγραμμα δεν ανοίγει

- Δοκίμασε να το τρέξεις ως Administrator.
- Έλεγξε αν το antivirus σου το μπλόκαρε (συμβαίνει).
- Κοίταξε για logs στο φάκελο εγκατάστασης: `Inkpath_Log.txt`.

### Κρασάρει κατά το save/load

- Κλείσε προσωρινά το antivirus.
- Βεβαιώσου ότι ο φάκελος δεν είναι μπλοκαρισμένος.
- Χρησιμοποίησε το autosave: `%TEMP%\Inkpath_Autosave.sav`.

### Δεν ανοίγουν οι εικόνες/ήχοι

- Βεβαιώσου ότι τα αρχεία υπάρχουν και τα paths είναι σωστά.
- Supported formats:  
  - Εικόνες: PNG, JPG, BMP, GIF  
  - Ήχοι: MP3, WAV, OGG

# 🛠️ Inkpath Path Changer - Βοηθητικό Εργαλείο

## Τι είναι το Path Changer;

Το **Inkpath Path Changer** είναι ένα ξεχωριστό εργαλείο που σας βοηθά να αλλάξετε **μαζικά** τις διαδρομές των εικόνων και ήχων στις ιστορίες σας. Ιδανικό για όταν:

- 🚚 **Μετακομίζετε** τις ιστορίες σας σε νέο φάκελο
- 💻 **Μοιράζεστε** ιστορίες με φίλους (για να δουλέψουν σωστά οι διαδρομές)
- 🔧 **Αλλάζετε τη δομή** των φακέλων σας

## Πότε το χρειάζεσαι;

Αν έχετε μια ιστορία με διαδρομές όπως:
Image=C:\Users\Νίκος\Εικόνες\scene1.png
Audio=D:\MyMusic\background.mp3

text

Και θέλετε να γίνουν:
Image=C:\Inkpath\EP\EPImages\scene1.png
Audio=C:\Inkpath\EP\EPSounds\background.mp3

text

## 📖 Οδηγίες Χρήσης

### Βήμα 1: Εκκίνηση
1. Κάντε διπλό κλικ στο `Inkpath_Path_Changer.ahk` (ή στο .exe αν είναι μεταγλωττισμένο)
2. Θα ανοίξει ένα παράθυρο με όλα τα απαραίτητα πεδία

### Βήμα 2: Επιλογή Αρχείου
1. Κάντε κλικ στο **"Επιλογή..."** δίπλα στο "Αρχείο Εισόδου"
2. Επιλέξτε το `.swp` αρχείο της ιστορίας σας
3. Το πρόγραμμα θα **αναγνώσει αυτόματα** τις τρέχουσες διαδρομές

### Βήμα 3: Ορισμός Νέων Διαδρομών
- Στο **"Images:"** βάλτε τη νέα διαδρομή για τις εικόνες (π.χ. `C:\Inkpath\EP\EPImages`)
- Στο **"Audio:"** βάλτε τη νέα διαδρομή για τους ήχους (π.χ. `C:\Inkpath\EP\EPSounds`)

### Βήμα 4: Αποθήκευση
1. Κάντε κλικ στο **"Επιλογή..."** δίπλα στο "Αρχείο Εξόδου"
2. Ονομάστε το νέο αρχείο (π.χ. `my_story_modified.swp`)
3. Προτείνεται να κρατήσετε το πρωτότυπο αρχείο ως backup

### Βήμα 5: Μετατροπή
1. Κάντε κλικ στο **"⚡ ΜΕΤΑΤΡΟΠΗ ΑΡΧΕΙΟΥ"**
2. Περιμένετε το μήνυμα επιτυχίας
3. Ανοίξτε το νέο αρχείο στο Inkpath για έλεγχο

## 🎯 Συμβουλές Χρήσης

### Προετοιμασία Φακέλων
Πριν τη μετατροπή, βεβαιωθείτε ότι:
C:\Inkpath\EP\EPImages\ ← Οι εικόνες σας είναι ΕΔΩ
C:\Inkpath\EP\EPSounds\ ← Οι ήχοι σας είναι ΕΔΩ

text

### Δοκιμή
Μετά τη μετατροπή:
1. Ανοίξτε τη νέα ιστορία στο Inkpath
2. Ελέγξτε 2-3 σκηνές ότι φορτώνονται σωστά οι εικόνες/ήχοι
3. Παίξτε την ιστορία για επιβεβαίωση

## ⚠️ Προειδοποιήσεις

- **ΠΑΝΤΑ** κρατήστε αντίγραφο ασφαλείας του αρχικού αρχείου
- Οι διαδρομές πρέπει να υπάρχουν πριν τη μετατροπή
- Το πρόγραμμα αλλάζει ΜΟΝΟ το path, όχι τα ονόματα των αρχείων

## 🔧 Αντιμετώπιση Προβλημάτων

**Δεν βρίσκει διαδρομές:** Μπορεί η ιστορία σας να μην έχει εικόνες/ήχους ή να χρησιμοποιεί σχετικές διαδρομές

**Σφάλμα αποθήκευσης:** Βεβαιωθείτε ότι έχετε δικαιώματα εγγραφής στον φάκελο προορισμού

**Δεν αλλάζει όλες τις διαδρομές:** Κάποιες διαδρομές μπορεί να έχουν διαφορετική μορφοποίηση

**Το εργαλείο δεν ανοίγει:** Βεβαιωθείτε ότι έχετε εγκατεστημένο το AutoHotkey v2.0+
